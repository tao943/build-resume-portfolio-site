# Content Planning Contract

Create `.resume-site-work/reports/content-implementation-plan.json` only after
`content-design-spec.json` has explicit user approval.

Each task records:

- stable task ID;
- fact and evidence IDs;
- exact target package files;
- copy blocks produced;
- unsupported claims that remain blocked;
- exact verification commands.

The plan ends with handoff criteria. Validate the plan before drafting or
rewriting copy. Never turn an unsupported claim into prose merely to complete a
task.
