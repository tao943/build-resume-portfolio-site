# Select compatible optional second-layer motion recipes

Preserve the confirmed React + Vite website. Read only the short `manifest.json`, shortlist recipes from its summaries, then load only those candidate recipe JSON files. Never load all raw source prompts and never redesign the page.

Match the resume domain, existing composition, palette, typography, media availability, and performance needs. Select multiple primary recipes and multiple secondary effects when they are compatible; there is no numeric effect cap. Do not select an effect that adds another media layer, WebGL canvas, or a competing hero focal point unless the confirmed direction specifically requires it.

Return JSON containing `primary_recipe_ids`, `secondary_effect_ids`, `items`, concise `selection_reasons`, `rejected_candidates`, and `preserve`. Every item has a unique `id` and declares `source`, `target`, `purpose`, `controllers`, `dependencies`, `conflict_resolution`, `cleanup`, `mobile`, `reduced_motion`, and `fallback`. Reject unknown or duplicate recipe IDs; resolve every shared target/controller combination with a non-empty `conflict_resolution`. Preserve resume facts, section order, palette, typography, responsive hierarchy, Poster/media safety, and the `confirmed_media_direction_baseline` regardless of whether React Bits was used.
