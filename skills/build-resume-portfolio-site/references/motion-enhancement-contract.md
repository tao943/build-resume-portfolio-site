# Motion Enhancement Contract

Stage 5 is optional and begins only after the production-hardened motion baseline is confirmed. It may select multiple compatible primary recipes and multiple compatible secondary effects; there is no numeric effect cap.

Runtime selection reads the catalog manifest and only shortlisted recipe JSON files. Raw source prompts are provenance, not runtime context. A recipe is adaptation guidance: the confirmed page theme, content, layout, palette, typography, breakpoints, and section order are immutable inputs.

Each selected recipe/effect has a unique ID and declares its source, target, purpose, controllers, dependencies, conflict_resolution, cleanup, mobile behavior, reduced-motion behavior, and fallback. Reject unknown or duplicate recipe IDs. When selections share a target/controller combination, provide a non-empty conflict_resolution that explains the shared timeline or isolation.

Poster-only is a complete successful result. Video is an optional later upgrade. All media playback is passive; scroll-linked playback, pointer-linked playback, timeline scrubbing, autoplay audio, and remote video URLs are forbidden. Preserve factual content, responsive hierarchy, Poster/media safety, and the source-agnostic `confirmed_media_direction_baseline`.
