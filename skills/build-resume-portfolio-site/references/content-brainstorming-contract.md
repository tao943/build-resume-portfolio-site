# Content Brainstorming Contract

Use full discovery for a new content package or when facts, target role,
positioning, narrative, or approved copy changes.

1. Inventory evidence and assign stable fact/evidence IDs.
2. Ask one decision-bearing question at a time.
3. Resolve identity, dates, scope, outcomes, metrics, and target audience
   before tone preferences.
4. Compare two or three materially different content strategies.
5. Recommend one with explicit trade-offs.
6. Write `reports/content-design-spec.json`.
7. Validate it and wait for explicit strategy approval.

Strategy approval chooses how content will be shaped. It does not approve the
final wording.

A fast change is allowed only for a bounded revision to an existing approved
package that introduces no new fact, claim, target audience, or positioning.
