# 三分钟初赛演示脚本

## 演示准备

- 使用 `anonymized-student-resume.md` 和 `target-jd.md`。
- 预先确认 Worker 和星辰自定义工具均已发布。
- 全程不展示真实简历、密钥、平台凭据或未脱敏日志。
- 录制前用新的星辰会话完成一次全链调试。

## 00:00—00:25｜问题与输入

旁白：大学生常有项目，但难以判断哪些内容可信、怎样匹配岗位，以及怎样把
经历变成可分享的个人作品集。将匿名简历和目标 JD 交给智能体。

操作：粘贴两份演示材料，公开姓名填写“候选人 A”，联系方式保持不公开。

## 00:25—00:55｜事实核验

展示 `FACT-*` 和 `EVID-*` 证据关系。智能体发现校园活动信息助手存在
2025.03 与 2025.04 两个启动时间，只询问一个问题。

演示回答：“以 2025.04 为正式开发开始时间，2025.03 是前期调研，不在项目
日期中体现。”确认后继续，强调智能体没有静默选择更好看的日期。

## 00:55—01:20｜岗位匹配

展示 JD 匹配矩阵。Python、React、检索原型和需求迭代均连接到具体事实；
Kubernetes 生产运维和两年商业经验保持 `unmatched`，不会被写进简历。

## 01:20—01:45｜内容策略批准

展示“AI 应用闭环”“用户问题驱动”和“工程基础成长”三种叙事及其利弊。接受
智能体推荐的“AI 应用闭环”，在问答节点完成内容策略批准。

## 01:45—02:05｜最终文案批准

检查岗位定制文案中的项目职责、技术和结果均能回到证据 ID。指出没有虚构指标
或 Kubernetes 关键词，然后在独立问答节点完成最终文案批准。

## 02:05—02:30｜创意方向批准

比较两个或三个内容驱动方向，例如“证据台账”“检索路径”和“迭代现场”。展示
推荐理由和移动端降级方案，选择“证据台账”，完成创意方向批准。

## 02:30—02:50｜在线预览

星辰生成自包含 HTML，自定义工具返回在线预览 URL。打开页面，展示非通用卡片
模板的构图、证据主角和移动端媒体规则。说明浏览器访问本身不构成批准。

## 02:50—03:00｜价值总结

总结认知—决策—执行闭环：核验事实、匹配岗位、批准文案、批准创意并交付可分享
预览。复赛可接回完整 React/Vite 建站、更多视觉选择和版本回滚。
